# KPanel 图库设计

- 状态：本地候选（`claude/media-gallery`），未合入主线；正式状态以候选门禁、浏览器验收和发布记录为准
- 路由：`/gallery`（可带 `path=<绝对路径>` 与 `hostId=<集群主机>`）
- 入口：桌面模式独立图标“图库”（开始菜单同步出现）；文件管理顶部命令栏“图库”按钮以图库方式打开当前文件夹；
  经典模式不增加左侧主导航，与历史监控、进程管理器、系统中心一致
- 真源：宿主机上的普通文件夹；不建索引、不存数据库影子、不新增后端 API 或信任边界

## 1. 产品目标

让管理员把服务器当作一个安静的私人相册：上传照片和视频，按月份浏览，按相册整理，在沉浸式查看器里
看大图和播放视频。照片永远是普通文件——文件管理能看到、能移动、能备份，图库只是更好看的呈现方式，
删除和重命名也走文件管理同一条链路。

## 2. 数据模型

| 概念 | 落在宿主机上 | 说明 |
| --- | --- | --- |
| 图库位置 | 一个文件夹，默认 `/home/gallery` | 只保存在当前浏览器（`localStorage` `kpanel:gallery:v1`），不能是根目录 `/` |
| 照片/视频 | 文件夹里的文件 | 扩展名优先识别（宿主机 `mime.types` 不可靠），MIME 只补充未知扩展名；SVG 与点文件不算媒体 |
| 相册 | 图库位置的直接子文件夹 | 点开相册时同样展示它的直接子文件夹作为子相册 |
| 时间线 | 当前文件夹及其直接子文件夹中的媒体 | 按修改时间分月；“按名称”排序时不分组 |

读取边界（`web/src/lib/galleryLibrary.ts`）：每页 500 项，当前文件夹最多 10 页，最多汇总 48 个子相册、
每个相册最多 4 页，4 路并发；达到边界时界面明确提示“仅汇总了部分内容”。单个相册读取失败只跳过该相册并提示。

## 3. 复用的文件链路

| 能力 | 复用接口 | 约束 |
| --- | --- | --- |
| 列表 | `GET /api/v1/files`（新增前端可选 `limit`，Agent 上限 500） | Session；`hostId` 走既有集群文件中继 |
| 缩略图 | `GET /api/v1/files/content?mode=thumbnail&version=` | Agent 仅缩放 JPEG/PNG/GIF（≤12 MB，320×210 框）；失败时回退原图（≤16 MB） |
| 原图/视频 | `GET /api/v1/files/content?disposition=inline` | Range 流式播放；视频画面不可解码时提示转码 |
| 上传 | `POST /api/v1/files/upload`（`overwrite=false`） | 2 路并发（对齐 Agent 上传闸门）；重名永不覆盖，自动改为 `name (2).ext` |
| 新建/重命名/删除 | `POST /api/v1/files/actions` 的 `mkdir`/`rename`/`trash` | 删除只移入回收站，携带 `expectedResourceVersions` |
| 下载 | 既有 `downloadFileEntries`（单文件票据、多文件 ZIP） | 与文件管理一致 |

图库改动后通过 `notifyFileDirectoriesChanged` 通知已打开的文件管理窗口；文件管理里的改动同样会让图库刷新。

## 4. 呈现

- 顶部封面：最新一张原图 ≤12 MB 的照片铺满并加底部暗化（没有时才用缩略图），标题、统计（照片/视频/相册/体积）、路径与主要操作。
- 相册：4:3 封面卡片，封面优先最新静态照片；卡片菜单提供重命名、在文件管理中打开、删除。
- 工具栏（吸顶）：全部/照片/视频分段、文件名搜索、最新/最早/名称排序、紧凑/标准/舒展三档密度、选择模式。
- 时间线：方形网格，每月第一项在 ≥5 项时以 2×2 精选块呈现（精选块优先用 ≤12 MB 原图保证清晰）；
  视频在进入视口后挂载一次 `<video preload="metadata">`，把首帧截成 ≤640px 的 JPEG 海报并释放播放器
  （Chromium 限制同时存在的媒体播放器数量；海报按文件版本缓存在本标签页，最多 240 张），悬停 0.4 秒才重新挂载静音预览，角标显示时长；
  浏览器无法显示的格式（HEIC/TIFF 等）显示格式占位，查看器提供下载。渲染按 240 项分批追加。
- 查看器：深色沉浸背景（当前图模糊环境光）、缩略图先显示再淡入原图、滚轮/双击/按钮缩放与拖动平移、
  左右键与横向滑动翻页、`i` 详细信息、`Delete` 移入回收站、全屏；底部胶片条。经典模式覆盖视口，
  桌面窗口内只覆盖该窗口。
- 上传：拖入整页出现投放层；右下角上传队列显示整体与单项进度、取消、失败重试；非媒体文件跳过并提示。

视觉遵守 [`ui-visual-language.md`](ui-visual-language.md)：最小字号 12px（时长角标、计数），正文与按钮 14px；
圆角只用语义 Token；查看器的固定深色调色板只在查看器内部定义。

## 5. 已知边界

- 图库位置按浏览器保存，换浏览器需要重新设置（默认位置一致时无需设置）。
- 时间线使用修改时间而非 EXIF 拍摄时间；Agent 缩略图上限为 320×210，在高 DPI 屏幕上普通网格略软，精选块用原图。
- 远端主机（`hostId`）复用文件中继，受其限流约束；首版只从文件管理入口进入远端图库。
- 不做人脸/地点识别、不生成持久化缩略图、不修改媒体元数据。

## 6. 验证与回滚

- 自动化：`gallery.test.ts`（识别、排序分组、路径与命名、偏好）、`galleryPosters.test.ts`（海报缓存与上限）、`galleryLibrary.test.ts`（分页与边界、缺失文件夹、
  单相册失败、取消）、`GalleryView.test.ts`（相册与时间线、筛选与导航、创建图库、上传重名、查看器键盘与删除后续看、相册删除、回收站）。
- 本地 UI Mock 预览：`scripts/mock-gallery.mjs` 在内存中提供 `/home/gallery`，可用 `KPANEL_MOCK_GALLERY_DIR` 指向样例目录
  （文件夹即相册，`.thumbs/` 提供缩略图）；不写任何宿主机文件。
- 回滚：前端独立路由与入口，回退本候选提交即可；不涉及数据迁移，用户上传的文件仍留在宿主机文件夹中。
