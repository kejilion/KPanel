# KPanel 广告专栏设计

- 状态：本地候选（`claude/offers-column`），未合入主线；正式状态以候选门禁、浏览器验收和发布记录为准
- 路由：`/offers`；界面名称「广告专栏」，英文 “Sponsored”，繁体「廣告專欄」
- 入口：经典模式顶栏右上角小图标按钮（语言选择之后、「进入桌面」之前）；桌面模式固定图标
  `nav:/offers`，可像应用和网站一样从桌面移除并在「桌面布局管理」恢复，开始菜单始终可打开
- 真源：`https://app.kejilion.sh/offers/v1.json` 及其固定 SHA-256 的横幅图片，与应用市场目录同站发布；
  Panel 只缓存，不保存第二份业务事实
- 视觉与可读性：遵守 [`ui-visual-language.md`](ui-visual-language.md)，本文件只补充广告专栏特有的版面与素材规则

## 1. 目标与非目标

用一页精致的横幅墙展示科技lion 推荐的服务器与域名厂商（AFF 推广），替代脚本「广告专栏」菜单里的纯文本
链接。页面只展示厂商宣传横幅，不自建价格、规格或购买卡片；价格以横幅和厂商页面为准。

非目标：KPanel 不经手订单和付款，不嵌入厂商页面，不统计点击，不做弹窗、插屏、启动广告或声音，
不检测或对抗广告拦截插件。

## 2. 入口

| 模式 | 呈现 | 规则 |
| --- | --- | --- |
| 经典 | 顶栏 40px 中性图标按钮（`Megaphone`），提示与读屏名称「广告专栏」 | 不加文字和红点；当前页时 `aria-current="page"`；≤ 680px 随顶栏改为 44px；「进入桌面」仍是唯一品牌色按钮 |
| 桌面 | 固定图标 `offers-kpanel-flat-v1.webp`（512×512，扁平黏土风格扩音器） | 唯一可隐藏的固定入口；右键「从桌面移除」只写 `hiddenEntryKeys`，图标管理可恢复 |
| 开始菜单 | 与其他系统应用并列 | 隐藏后仍列出并标注「桌面已隐藏」，可直接打开 |

## 3. 页面结构与排版

自上而下固定顺序，区块没有数据时整块不渲染：

| 区块 | 内容 | 规则 |
| --- | --- | --- |
| 说明行 | 一句返利说明、更新时间、刷新按钮 | 说明必须出现「返利/AFF」；页面标题由经典顶栏或桌面窗口标题承担 |
| 状态条 | 刷新失败时的琥珀色提示与重试 | 只在显示旧内容时出现，写明内容获取日期 |
| 主推轮播 | `featured` 横幅 1–3 张（4:1）+ 下方说明条 | 1 张时不显示控件；说明条含「广告」标记、厂商名、替代文本和目标域名 |
| 横幅墙 | 其余横幅（2:1），按清单顺序 | 每张下方「广告」标记 + 厂商名 + 目标域名；末尾固定「更多 VPS 优惠」（kejilion.pro/topvps） |
| 关于广告 | 返利、价格以厂商为准、不记录点击 | 永远在页底 |

栅格按**页面容器宽度**判断（`ResizeObserver`），桌面窗口与经典页面同宽同版：

| 容器宽度 | 主推轮播 | 横幅墙 | 说明条 |
| --- | --- | --- | --- |
| ≥ 1088px | 4:1 素材 | 3 列 | 单行 |
| 720–1087px | 4:1 素材 | 2 列 | 两行：标记与文案 / 域名与控件 |
| < 720px | 改用同厂商 2:1 素材 | 1 列 | 三行 |

末行补齐：「更多 VPS 优惠」在末行剩 1 格时占 1 格；3 列剩 2 格时横跨 2 格并与同行等高；末行已满或 1 列时
改为整行横条。列间距 16px、行间距 20px，区块间距 24px。两个断点都保证墙内横幅不窄于 352px
（2×352+16、3×352+2×16），1440 宽屏幕在展开侧栏的经典模式下为 3 列。

KPanel 统一绘制版面，厂商图片只管画面本身：主推圆角 `--radius-lg` 并与说明条合成一块；墙内圆角
`--radius`，加 1px 内描边防止深色图融进深色页面；静止 `--shadow-sm`，悬停 `--shadow-md` 并上移 2px。
「广告」标记使用 `--amber-soft`/`--amber`（浅色 5.7:1、深色 6.9:1），全站只有广告标记使用这组颜色；
厂商品牌色只出现在图片里。页面文字：分区标题 18/600，正文与按钮 14px，域名与元信息 13px，标记 12/600。

动效只用令牌：轮播 6 秒切换、`--motion-duration-base` 淡入淡出；悬停、键盘焦点在内、页面或桌面窗口
不可见、用户暂停或 `prefers-reduced-motion` 时不自动切换。横幅悬停用 `--motion-duration-fast`。

## 4. 横幅素材规格（交给厂商或统一模板）

| 用途 | 尺寸 | 体积 | 安全区 | 图内最小字号 |
| --- | --- | --- | --- | --- |
| 横幅墙、窄屏主推（必交） | **960×480**（2:1） | ≤ 200 KB | 四周 32px | 36px（源图像素） |
| 主推轮播（仅 `featured`） | **1600×400**（4:1） | ≤ 300 KB | 四周 48px | 28px（源图像素） |

- 最小字号按最窄显示宽度倒推：2:1 横幅最窄约 352px（2 列、720px 容器），缩放 0.37，36px ≈ 13px；
  4:1 最窄在 720px 容器，缩放 0.45，28px ≈ 12.6px，均不低于 12px 底线。
- 静态 WebP / PNG / JPEG，尺寸必须精确匹配，满版不透明背景；不自带圆角、白边、边框或阴影。
- 主推 4:1 与 2:1 必须表达同一内容；图里写了价格的条目必须给 `validUntil`。
- 不接受 GIF、视频、HTML5、伪造的关闭/下载/系统提示按钮、倒计时、闪烁和二维码。
- 审核时优先：深色或饱和底色、左对齐至多三层文字（厂商 / 标题 / 价格或卖点），主视觉在右。

## 5. 清单契约 `offers/v1.json`

```json
{
  "schemaVersion": 1,
  "updatedAt": "2026-10-10T00:00:00+08:00",
  "items": [
    {
      "id": "jtti",
      "vendor": "Jtti",
      "alt": "香港 CN2 云服务器，高防 IP 可选",
      "featured": true,
      "images": {
        "card": { "path": "offers/jtti-960x480.webp", "sha256": "<64 位小写十六进制>" },
        "wide": { "path": "offers/jtti-1600x400.webp", "sha256": "<64 位小写十六进制>" }
      },
      "url": "https://www.jtti.cc/zh/offers?k=kejilion",
      "validFrom": "2026-10-10T00:00:00+08:00",
      "validUntil": "2026-12-31T23:59:59+08:00"
    }
  ]
}
```

校验（`internal/offers/manifest.go`，严格 JSON、拒绝未知字段与尾随数据）：

| 字段 | 规则 |
| --- | --- |
| 清单 | ≤ 64 KiB；`Content-Type: application/json`；`schemaVersion` 为 1；`updatedAt` 必填 |
| `items` | 0–24 项，按数组顺序展示；`featured` 至多 3 项 |
| `id` | `^[a-z0-9][a-z0-9-]{0,47}$`，唯一 |
| `vendor` / `alt` | 1–32 / 1–80 个字符，无首尾空白与控制字符；`alt` 用于读屏和图片失败替身 |
| `url` | 绝对 `https`，无账号口令、无空白，≤ 512 字节 |
| `images.card` | 必填；`path` 为 `offers/<名称>.(webp|png|jpg)`，`sha256` 为小写十六进制 |
| `images.wide` | `featured` 必填，非主推禁止 |
| `validFrom` / `validUntil` | 可选 RFC 3339 时间，`validUntil` 晚于 `validFrom`；窗口外的条目不显示 |

## 6. Panel 行为与接口

- `internal/offers` 由无特权 Panel 进程执行出站读取，不经过 Agent。只访问固定 `https://app.kejilion.sh`，
  复用 `remotedownload` 客户端（DNS/IP 校验、拒绝重定向、超时、空闲断开），清单 64 KiB、图片按槽位
  200/300 KiB 读取上限。
- **全有或全无**：清单校验通过且每张图片的 SHA-256、扩展名对应的真实格式、精确尺寸和完整解码都通过后，
  才原子替换缓存；任一失败保留上一份内容，状态为 `stale`。
- 缓存位于 `<DataDir>/offers/`（目录 0700，文件 0600）：`state.json`（≤ 256 KiB，含来源与获取时间）和
  `objects/<sha256>`；只保留当前清单引用的对象，上限约 24×200 KiB + 3×300 KiB。缓存可丢弃，不进入备份。
- 刷新节奏：成功后 6 小时内直接使用缓存，过期时先返回旧内容再后台刷新；失败后 10 分钟内不自动重试；
  管理员手动刷新每分钟至多一次。首次没有缓存时同步等待一次有界下载（≤ 45 秒）。
- `GET /api/v1/offers[?refresh=1]`：需要 Session，`Cache-Control: no-store`；只接受这一个查询参数。返回
  `state`（`live`/`stale`/`unavailable`）、`updatedAt`、`fetchedAt` 和窗口内条目，图片为同源路径。
- `GET /api/v1/offers/media/<sha256>`：需要 Session，只服务当前清单引用的摘要，按文件签名给出
  `Content-Type`，`private, max-age=31536000, immutable` 与 ETag。前端再次校验图片路径和 `https` 链接，
  不合格条目直接丢弃。

## 7. 标识与约束

- 每张横幅都有可见「广告」标记和目标域名；链接 `target="_blank"`、`rel="sponsored noopener noreferrer"`。
- 读屏名称为「厂商：替代文本（广告，在新标签页打开 域名）」；厂商名与替代文本标记 `data-i18n-ignore`。
- 路由、类名、接口和图片路径不使用 ad / ads / banner / sponsor / promo，避免拦截插件按规则误隐藏面板
  其他区域或让接口报错；被拦截时页面其余部分照常可用，不提示关闭拦截。
- Panel CSP 仍为 `img-src 'self' data: blob:`，浏览器从不直连厂商或图床。

## 8. 失败、降级与回滚

| 情况 | 呈现 |
| --- | --- |
| 首次加载 | 按真实比例的骨架 |
| 接口请求失败 | 错误说明与重试 |
| 从未取到清单 | 说明内容来自 app.kejilion.sh、请确认面板能访问外网，可重试 |
| 刷新失败但有缓存 | 琥珀色状态条注明获取日期，内容照常可用 |
| 清单为空或全部过期 | 空状态，提供 kejilion.pro/topvps 链接 |
| 单张图片失败 | 同尺寸文字替身（厂商名 + 替代文本） |
| 缓存目录不可用 | 状态 `unavailable`，不影响面板其他功能 |

回滚：撤销本候选提交即可，缓存目录 `<DataDir>/offers/` 可直接删除。若管理员已把广告专栏从桌面移除，
`workspace.json` 的 `hiddenEntryKeys` 会含 `nav:/offers`；不认识该键的旧版本会按既有损坏处理把桌面工作区
判为无效并只读降级（保留文件、不丢数据），与读取更高 schema 时相同。回滚前先在新版本「桌面布局管理」
恢复该图标即可避免。

## 9. 发布方操作（应用市场站点）

1. 在应用市场站点仓库放置 `offers/v1.json` 和 `offers/*` 图片，图片按第 4 节导出，清单中的 SHA-256
   与文件逐字节一致。
2. 发布前用与 Panel 相同的规则本地校验；发布后 `curl -fsSI https://app.kejilion.sh/offers/v1.json`
   应返回 `200` 与 `application/json`，图片返回对应 `image/*`。
3. Panel 最迟 6 小时后自动更新，管理员也可在页面点刷新。换横幅不需要发布 KPanel 版本。

## 10. 验证

- Go：清单与图片校验、全有或全无、无缓存/失败退避、强制刷新限频、过期后台刷新、重启恢复与清理、
  发布窗口、Content-Type 错配（`internal/offers`，含 `-race`）；接口鉴权、方法、查询参数、媒体头与条件请求
  （`internal/panel/offers_test.go`）；`nav:/offers` 可隐藏、其他固定入口仍被拒绝（`internal/desktopworkspace`）。
- 前端：轮播、暂停与减少动效、末行补齐三种形态、状态条、不可用/空/错误/图片失败、刷新；客户端过滤
  非 https 链接和非同源图片；桌面移除与恢复、全选删除只涉及广告专栏、开始菜单计数。
- 未验证：真实 `app.kejilion.sh/offers/` 发布内容、厂商真实素材、真实宿主机与生产、广告拦截插件实测。
