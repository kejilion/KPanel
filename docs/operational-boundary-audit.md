# KPanel 操作边界审计

审计基线：

- KPanel：`bcfcb7b`（v0.18.1 基线）及本次整改工作区；
- `kejilion.sh`：本地仓库 `af8fe7c`；
- 审计目标：删除“管理员可能误操作”为理由的能力门槛，保留防攻击、并发完整性和真实技术前置条件。

状态定义：

- **已移除**：后端不再据此拒绝，前端不再隐藏对应动作；
- **完整性校验**：不决定资源归属权限，只防注入、路径越界、并发覆盖或半成品事务；
- **适配缺口**：底层 Web 适配器尚未实现，不得表述为安全限制或已完成。

## 全局边界

| 检查项 | 结论 |
| --- | --- |
| 登录、Session、CSRF/Origin、Agent Token、Unix Socket | 保留，属于防未授权访问 |
| API 类型、路径、名称、端口和配置语法校验 | 保留，属于防注入和路径穿越 |
| `resourceVersion`、任务互斥、提交前回读 | 保留，属于并发完整性 |
| 固定确认词、复选框作为后端授权条件 | 已移除；普通确认仅表达用户意图 |
| resource origin、KPanel label、marker、人工漂移作为授权条件 | 已移除 |
| 以“危险”“会离线”“KPanel 自身”为由拒绝 | 已移除 |
| Agent 离线或协议不兼容 | 技术依赖状态；不得伪装成资源只读策略 |

## 系统监控与管理

| 功能 | 已移除的操作护栏 | 保留边界 / 当前缺口 |
| --- | --- | --- |
| 主机名 | 无来源或固定确认限制 | Linux hostname 语法、原子写入和回读 |
| SSH 端口 | 不因端口已被其他服务占用而预先拒绝；交给可信 `kejilion.sh` 原有主业务切换 | `1-65535`、执行前备份、脚本协议标记和配置回读；云安全组需单独放行 |
| DNS | IPv4/IPv6 可同时提交；不按 DNS 管理器来源限制管理员操作 | IP 语法；最多 2 个 IPv4 与 2 个 IPv6；要求可信 `kejilion.sh` DNS 非交互协议，失败由脚本事务回滚 |
| 时区 | 无固定选项授权限制 | 时区必须真实存在于 IANA 数据库 |
| Swap | 移除 256–65536 MiB 与内存余量门槛；允许 0 或任意正整数 MiB | `/swapfile` 事务和回滚保留；当前仍保留其他 Swap，和脚本清理分区的副作用存在差异 |
| 系统源 | 移除固定镜像域名授权表，可改写任意符合 Debian/Ubuntu 仓库路径的源 | APT 语法、独立索引验证和回滚；其他发行版换源适配器未实现 |
| V4/V6 优先 | 不要求 KPanel marker；识别并替换脚本同款 precedence 行 | 只修改对应 `gai.conf` 规则，避免误删无关配置 |
| 内核优化 | 未识别的同名脚本/人工配置不再阻止执行；请求会先备份再按所选模式覆盖 | 固定预设、sysctl 回读和失败回滚；通用 sysctl 编辑器未实现 |
| BBR | 同名配置是否由 KPanel 创建不影响启用/停用 | 内核必须实际提供 BBR；写入失败回滚 |
| 更新/清理 | 不使用发行版“安全白名单”措辞；按实际包管理器探测 | systemd 后台任务和原生命令适配；APK/日志清理副作用尚未与脚本逐项完全一致 |
| 重启 | 移除 `REBOOT` 固定口令和维护任务占用限制 | 登录、CSRF、普通确认、固定 systemd 延时动作 |
| 重装系统 | 不再标记“受保护/永久锁定” | **适配缺口**：镜像参数、离线任务及重装后结果回传未实现 |

## 网站管理

| 功能 | 已移除的操作护栏 | 保留边界 / 当前缺口 |
| --- | --- | --- |
| 发现 | 脚本、Web、人工配置、重复域名和孤立产物均显示 | 配置读取失败仍返回实际文件资源 ID |
| 更新 | 不要求 Web origin；漂移配置转入当前结构补丁更新 | Nginx 结构无法无歧义解析时为**更新适配缺口**，不是来源只读 |
| 删除 | 不要求逐字输入域名；不要求 marker、原始 hash、固定 `k web` 目录形状或数据库适配器 | 删除路径必须位于共享 Web 根；Nginx 失败回滚；数据库失败返回警告而不恢复已删站点 |
| 反向代理 | 不限制公网 IP、FQDN 或非回环上游 | URL/端口语法和 Nginx `-t` |
| 外联配置来源 | 不允许以“兼容”为名维护 KPanel 自编模板 | WordPress 与 IP+端口反代已改为执行脚本固定非交互分支；`managed_template.go` 中其余网站类型仍为**冻结迁移债务** |
| Nginx / LDNMP | label、镜像、特权、host network 和额外设备不再作为授权条件 | 固定服务名及共享 `/home/web` 挂载是读写同一业务产物的技术契约 |
| 一键建站 | 复用 `kejilion.sh` 非交互协议与真实产物 | 尚未协议化的脚本交互参数属于适配缺口 |

## 应用市场

| 功能 | 已移除的操作护栏 | 保留边界 / 当前缺口 |
| --- | --- | --- |
| 安装状态 | KPanel 专属 label 与静态 `.conf` 解析结果不再作为管理授权 | Docker、`appno.txt`、端口文件、Compose label/工作目录联合发现 |
| 兼容产物 | 安装/卸载不因脚本或人工改过端口文件、`appno.txt` 中存在未知行而拒绝；按当前动作事务更新目标条目并保留无关行 | 固定应用根、防符号链接越界、文件体积上限与失败恢复 |
| 第三方应用 | 动态 Shell 写法导致配置无法静态解析时，仍可复用脚本原生管理协议 | 远程目录只能提供展示元数据，不能注入执行命令 |
| 生命周期 | 脚本安装、特权、挂载、改镜像的主容器均可启动/停止/重启 | 必须发现真实主容器并符合当前 Docker 状态 |
| 更新/卸载 | 声明式应用不要求原镜像、无挂载、固定重启策略或 KPanel label | 更新/访问切换需识别约定 TCP 端口；脚本应用需本机非交互管理协议 |
| 域名与访问 | 不要求资源由 KPanel 创建 | 域名入口需要可识别 HTTP 端口；marker 存在但主容器不存在时没有可执行容器动作 |
| 初始信息 | 安装器原生输出直接进入持久化后台任务日志 | 仅向已登录管理员展示；审计副本继续脱敏 |
| 脚本许可 | 保留 `kejilion.sh` 自身 `permission_granted` 状态 | 这是脚本业务前置条件，不由 Web 伪造或绕过 |

## Docker 管理

| 功能 | 已移除的操作护栏 | 保留边界 / 当前缺口 |
| --- | --- | --- |
| 容器 | 全部来源、KPanel 自身、特权/host/设备/宿主机挂载容器均可管理；删除使用 force | Docker 实时状态和资源版本 |
| 日志/性能/控制台 | 不检查 ownership；运行中外部容器可执行单次控制台 | 输出脱敏、大小/时间上限；交互式 TTY 尚未实现 |
| 外部访问 | 多网络容器不再因存在多个 IPv4 拒绝 | 对每个 Docker IPv4 写入脚本兼容 `DOCKER-USER` 规则 |
| 新建容器 | 支持任意合法绑定 IP、命名卷自动创建、宿主机 bind mount | 特权、Capability、设备和更多 HostConfig 仍是创建表单缺口 |
| 镜像 | 删除不因被使用而在 KPanel 侧禁用，调用 Docker force remove | 最终结果由 Docker Engine 返回 |
| 网络 / 卷 | 不保护 builtin、in-use、KPanel 名称；支持自定义驱动 | 名称/驱动语法和资源版本 |
| 备份 | `/home/docker/kpanel` 与 `kpanel_port.conf` 不再排除 | 固定根、归档路径穿越、体积和条目上限 |
| 还原 | 不因目标已存在或包含 KPanel 自身而拒绝；事务覆盖并保留回滚副本 | 归档完整性、固定业务根和失败回滚 |
| 清理 / 卸载 | Prune 不要求固定确认词；Docker 卸载不应因会终止 KPanel 被禁用 | Docker 环境卸载的离线结果协议仍是适配缺口 |

## 防回退要求

1. 新功能先定位 `kejilion.sh` 菜单、函数、输入、产物和失败路径；
2. 自动化测试至少覆盖“脚本/外部产物可管理”和“KPanel 产物脚本可识别”各一条；
3. `scripts/check-ecosystem-policy.sh` 检查已删除的典型来源门槛和固定确认词不得回流；
4. 未实现项必须写“缺少适配器”，不得写“为了安全只读/受保护”；
5. 发布前执行 L3；普通改动只执行与变更范围匹配的 L0/L1/L2。
