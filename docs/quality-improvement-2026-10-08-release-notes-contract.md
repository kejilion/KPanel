## 观察证据与原因假设

RC12 的公开 [Release 正文](https://github.com/kejilion/KPanel/releases/tag/v1.25.0-rc.12)
包含 5 条用户更新及 3 条升级注意，标题为“新增与修复”和“使用与升级注意”；RC11 和稳定版 v1.24.0
使用“新增与改进”。基线 `internal/selfupdate/source.go` 不识别这些标题；生成器允许任意分类，
发布测试只覆盖标准标题。目标版本与正文存在不能证明摘要可读，网络问题不能解释这个确定性格式缺口。
根因假设可由同一真实 Changelog 正文经过实际来源解析、生成与发布门禁的回归证伪。

## 产品原则、范围与非目标

仅修改日志解析、生成、发布门禁、相关回归及权威规范/现有执行适配。继续使用 GitHub Release 与
Changelog 作为说明来源；不新增业务状态、网络入口或权限，不改变宿主资源、Panel/Agent 边界、
脚本与应用市场契约，也不改写已发布 Changelog、Tag、Release、历史验收记录或生产数据。
本地任务等级为 L1 加独立治理复核（局部 Go 包与说明门禁，没有 API、部署运行或权限契约变化），正式发行仍按 L3。
